# Package index

## Endpoints and scores

Define endpoints and compute posterior benefit-risk scores and win
statistics of observed or simulated data

- [`Endpoint()`](https://gosukehommaEX.github.io/OncoCohortSelect/reference/Endpoint.md)
  [`print(`*`<Endpoint>`*`)`](https://gosukehommaEX.github.io/OncoCohortSelect/reference/Endpoint.md)
  : Define an endpoint
- [`PosteriorProb()`](https://gosukehommaEX.github.io/OncoCohortSelect/reference/PosteriorProb.md)
  : Posterior probability of a favorable value of an endpoint
- [`BenefitRisk()`](https://gosukehommaEX.github.io/OncoCohortSelect/reference/BenefitRisk.md)
  : Posterior benefit-risk score of cohorts
- [`WinStat()`](https://gosukehommaEX.github.io/OncoCohortSelect/reference/WinStat.md)
  : Net treatment benefit, win ratio and win odds of prioritized
  endpoints

## Simulation

Simulate cohorts and evaluate selection rules

- [`SimCohorts()`](https://gosukehommaEX.github.io/OncoCohortSelect/reference/SimCohorts.md)
  : Simulate single-arm cohorts with correlated endpoints and an adverse
  event
- [`SimSelection()`](https://gosukehommaEX.github.io/OncoCohortSelect/reference/SimSelection.md)
  : Benefit-risk scores and win statistics of simulated trials
- [`SelectionOC()`](https://gosukehommaEX.github.io/OncoCohortSelect/reference/SelectionOC.md)
  : Selection probabilities of a decision rule
- [`CalibrateThreshold()`](https://gosukehommaEX.github.io/OncoCohortSelect/reference/CalibrateThreshold.md)
  : Threshold of a decision rule for a given false selection probability
